# PowerTile

macOS用のバッテリー情報表示メニューバーアプリ

## 機能

- バッテリー残量、充電状態のリアルタイム表示
- 充電ワット数、電圧、電流の表示
- バッテリー温度の監視
- バッテリーヘルス、サイクル数の確認
- 履歴グラフ表示
- ダークモード対応
- 日本語/英語対応

## インストール方法

### ダウンロード（推奨）
1. [Releases](https://github.com/ikepe/PowerTile/releases) から最新の `PowerTile.app.zip` をダウンロード
2. 解凍して `PowerTile.app` を「アプリケーション」フォルダに移動
3. **初回起動時のみ**：右クリック → 「開く」を選択

### ソースからビルド
1. このリポジトリをクローン
2. `PowerTile.xcodeproj` をXcodeで開く
3. Product → Build

## 動作環境

- macOS 13 (Ventura) 以降
- Apple Silicon / Intel Mac
